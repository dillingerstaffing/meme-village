# Camera key reset

The camera reset only through the speeds-row camera button, while
every other camera verb had already gained a keyboard twin, so a
desktop player with hands on the keyboard had to reach for the mouse
to get home after wandering. The Sims 4 camera guides give the player
a one-key return to the default view (Home in the Sims 4 guides, R
listed as the reset key in the Sims 3 camera table), and Meme Village
already serves a reset button with a fixed home view, so the missing
piece was the keyboard twin, not a new view.

R or Home runs exactly the camera button's verb: target 0,0,4, yaw 0,
dist 38, follow cleared, tray refreshed, so the key, the button, and
the opening camera cannot disagree. Like the button, reset needs no
selection and never changes one: resetting the view is a camera move,
not a deselection, and a followed resident simply stops being
followed because the camera is home.

The keys are guarded like key pan, key zoom, and F follow: they fire
only once the game has started, never while the game is over or an
incident panel is open, never with Ctrl, Meta, or Alt held, and never
while typing in a text field. The camera button title names the keys
it mirrors.
