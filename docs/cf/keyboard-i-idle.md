# Keyboard I idle finder

I is the keyboard twin of the tray Idle button: it runs exactly the
button's verb through the shared __cycleIdle, so the key, the button,
and the loafer count can never disagree. StarCraft II's Simplified
Controls guide gives Select Idle Worker its own key (F1: select, and
again centers); Meme Village's button already selects plus centers
in one tap, so the key adapts that verb in one press. F1 is the
browser help key and cannot be claimed, so I is the mnemonic, and
the Idle button's title names it ("Idle (I key)"), in the naming
grammar of the other keyboard verbs, so a desktop player can learn
I exists from the button itself.

I is guarded like a selection key, not like the display-only pause
and mute keys: it fires only once the game has started, never while
the game is over, never while an incident panel stands, never with
Ctrl, Meta, or Alt held, and never while typing in a text field.
Cycling changes the selection, so a press behind a modal decision
would answer that decision with a different resident selected than
the one the player chose under, exactly the failure the group digit
guard closes. Do not add an incident exception here without
re-arguing that selection rule: the guard is intentionally identical
to the camera and group keys, not to Space, P, 0, or M.
