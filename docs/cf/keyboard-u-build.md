# Keyboard U build order

U is the keyboard twin of the tray Build button: it runs exactly the
button's verb, so the key and the button can never disagree. The Build
button is disabled with no selection, so U needs a selection too:
ordering a build with no subject would send nobody anywhere, and the
button itself forbids it. With a building site open, U calls
setOrder3("build"), which carries the button's whole order grammar:
the sick and child answers, the standing-order answer ("is already
on the build"), the map-targeted arm clear on a real commit, and the
carry settle, all inside the shared order path rather than a second
copy. With no site open, U toasts the button's no-site wording
("No building site is open right now. Found a building first, or let
the current one finish.") instead of ordering, exactly as the button
does.

Build's initial B arms the Proclaim verb, so U, the button's second
letter, stands for it, in the second-letter grammar of O for Model
(M is the Sound mute key); U is claimed by no other key, so no
mnemonic compromise beyond that letter is needed. U closes the
queued "Build still unkeyed" item: the button-local Speak For
commit and the Cover chooser keep their own grammar and carry no
key, and the station order buttons in the Send-to group remain
mouse and tap only. The Build button's title
names it ("Build (U key)"), so a desktop player can learn U exists
from the button itself, in the StarCraft II command-hotkey grammar:
the hotkey shown on the button, not only in a tooltip.

U is guarded like a panel key, not like the display-only pause and
mute keys: it fires only once the game has started, never while
the game is over, never while an incident panel stands, never with
Ctrl, Meta, or Alt held, never while typing in a text field, and
never with no selection. An order behind a modal decision would
hide the decision it needs, so the incident guard is intentional,
not an omission. Do not add an incident exception here without
re-arguing that panel rule: the guard is intentionally identical
to the camera, group, idle, lens, story, thoughts, claim, proclaim,
found, road, visit, model, and spotlight keys, not to Space, P, 0,
or M.
