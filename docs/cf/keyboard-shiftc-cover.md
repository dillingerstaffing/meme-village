# Keyboard Shift+C cover chooser

Shift+C is the keyboard twin of the tray Cover button: it runs exactly
the button's verb, so the key, the button, and the tier chooser can
never disagree. For a banked adult with a bank account it opens the
tier chooser with the button's own arm toast (current tier, premiums
from the bank each season, each tier button names what it buys) and
the button's own armed-verb clear list (Spotlight, Model, Visit,
Proclaim, Speak For, Found, Groups). Since the button itself
disappears while the chooser stands, a second Shift+C closes the
chooser again, in the Lens toggle grammar, changing no tier: tapping
the tier already held is the button path's close, and the key path
needs a close of its own.

Shift+C is the first modifier chord in the tray grammar, and it exists
because every letter in Cover is already taken: C claims Claim, O is
Model, V is Visit, E rotates right, R resets the camera. Before this
chord, Shift+C misfired into Claim, because the Claim handler
accepted capital C with Shift held, so a player reaching for Cover
armed a Town claim instead. Shift names the second verb on a key
here, in the game's own control-group grammar (Shift plus a digit
assigns, the digit alone recalls) and in StarCraft II, where Shift
plus a number adds to a group while Ctrl plus a number creates it.
The plain C handler therefore stands aside while Shift is held; see
keyboard-c-claim.md.

Shift+C needs a selection, like the button, which renders only for
the selected resident, and only for a banked adult with an account:
with no selection, unbanked, a child, or no account, it does nothing,
exactly as an absent button does. It clears no tier and commits
nothing: the tier commit stays on the tier tap, so the key path can
never spend a premium by itself.

Shift+C is guarded like a panel key, not like the display-only pause
and mute keys: it fires only once the game has started, never while
the game is over, never while an incident panel stands, never with
Ctrl, Meta, or Alt held, and never while typing in a text field. A
chooser over a modal decision would hide the decision it needs, so
the incident guard is intentional, not an omission. Do not add an
incident exception here without re-arguing that panel rule: the
guard is intentionally identical to the camera, group, idle, lens,
story, thoughts, claim, proclaim, found, road, visit, model,
spotlight, build, and speak keys, not to Space, P, 0, or M. The
Cover button's title names it ("Cover (Shift+C key)"), so a desktop
player can learn Shift+C exists from the button itself, in the
StarCraft II command-hotkey grammar: the hotkey shown on the button,
not only in a tooltip.
