# Keyboard comma and period speed

Comma and period are the keyboard twins of the 1x and 2x speed
buttons: each key runs exactly the button's verb, setSpeed with
the button's rate, so the key and the button can never disagree.
Comma sets speed 1 and period sets speed 2, and the shifted forms
do the same (< sets 1, > sets 2), because Shift changes the
character the key reports and the pair must not go silent under
Shift. Pressing a speed key while paused unpauses at that rate,
exactly as tapping the button does, because setSpeed is the whole
verb on both paths.

The Sims names 1, 2, and 3 for regular, fast, and ultra speed, and
P or 0 for pause. This game already follows that grammar where it
can: Space, P, and 0 pause. The direct digits cannot carry the
speeds here, because 1, 2, and 3 recall control group slots, and
taking them back would break recall. Comma and period are the
adaptation: comma sits left of period as 1x sits left of 2x in the
speeds row, so the pair reads as slower and faster in button
order, and both keys are free (no letter, camera, tray, or speed
verb claims them, and plus and minus are zoom).

Speed is a sim-rate verb, not a resident verb: the keys need no
selection, like the pause keys, and they clear no arm, because
changing pace is never a sim order and must not silently cancel a
pending verb. They are guarded like a panel key, not like the
pause keys: they fire only once the game has started, never while
the game is over, never while an incident panel stands, never
with Ctrl, Meta, or Alt held, and never while typing in a text
field. The pause keys carry a deliberate incident exception
because pausing is the thinking tool during a decision; changing
to 2x behind a modal decision is not a thinking tool, it would
move a sim the player cannot see, so the incident guard is
intentional, not an omission. The buttons name the keys ("Normal
speed (, key)", "Fast speed (. key)"), so a desktop player can
learn them from the buttons themselves, in the StarCraft II
command-hotkey grammar: the hotkey shown on the button, not only
in a tooltip.

With this pair, every speeds-row button has a key: pause on Space,
P, and 0, normal speed on comma, fast speed on period, camera
reset on R or Home, rotate on Q and E, zoom on wheel, plus, and
minus, and view save on X. No speeds-row button is left keyless.
