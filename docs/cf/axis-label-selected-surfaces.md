# The Axis Label Shows Only Where a Resident Is Selected

A resident's axis chip (icon plus word pair) renders in exactly two
places: the tray role line while that resident is selected, and the
character sheet header. Never put it on overlays, the minimap, lists,
or any always-visible surface. The framework behind the axes is never
named in code, comments, UI text, or commit messages; code calls them
temperament axes. In the thought composer the fact is fixed first and
the axis reframes only the evaluative wording; an axis never adds a
fact, a name, or a count to a thought.

Why: the label is a reading aid for one person at a time. Shown
everywhere, temperament turns into a public stat players optimize
instead of a pattern they infer from watching behavior, which is the
opposite of what the character sheet is for.
