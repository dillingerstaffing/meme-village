# Keyboard T thoughts sheet

T is the keyboard twin of the tray Thoughts button: it runs exactly
the button's verb, dispatching ui/sheet for the selected resident,
so the key, the button, and the sheet can never disagree. The sheet
is the only surface that renders thoughts, and Escape already closes
it, so a desktop player who learned every other key from the buttons
still had to reach for the mouse to open it. T is the button's own
initial, in the naming grammar of I for Idle, M for Sound, and F for
Follow, and the Thoughts button's title names it ("Thoughts (T key)"),
so a desktop player can learn T exists from the button itself.

T is guarded like a panel key, not like the display-only pause and
mute keys: it fires only once the game has started, never while the
game is over, never while an incident panel stands, never with Ctrl,
Meta, or Alt held, and never while typing in a text field. Opening a
sheet over a modal decision would hide the decision it needs, so the
incident guard is intentional, not an omission. With no selection T
does nothing, like the disabled button: it never opens a sheet for a
resident the player has not chosen. Do not add an incident exception
here without re-arguing that panel rule: the guard is intentionally
identical to the camera, group, and idle keys, not to Space, P, 0,
or M.
