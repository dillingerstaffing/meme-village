# Keyboard K speak for

K is the keyboard twin of the tray Speak For button: it runs exactly the
button's verb, so the key and the button can never disagree. Speak For
is the one Influence verb with a two-tap grammar instead of a plain
arm: a first press with a valid plan arms speak and telegraphs the
plan (voucher, target, followers, trust, threshold), a second press
commits through speakFor, and a gated press (blame too low, or a
defense heard too recently) teaches the reason through speakFor
instead of arming. The key preserves that grammar in the button's
order: coverArm clears first, an armed press clears the arm and
commits, a gated press teaches, a valid plan arms and clears the
Groups arm with the button's own telegraph toast, and a planless press
teaches through speakFor. The telegraph toast keeps the button's
wording, so the key path and the button path cannot disagree about
what the second press commits.

Speak's letters are all taken except K: S pans the camera down in
WASD, P pauses, E rotates right, A pans left, so K, the only free
letter, stands for it, claimed by no other key. K is the fourth
resident-targeted Influence verb to gain a key, after Visit, Model,
and Spotlight. It needs no selection, unlike those three: the button
is never disabled, and speakPlan prefers a marked selected resident
but falls back to the scapegoat candidate, so K defends with nobody
selected exactly as the button does. It clears no other arm, like the
button, which clears only Cover and, on arming, Groups.

K is guarded like a panel key, not like the display-only pause and
mute keys: it fires only once the game has started, never while the
game is over, never while an incident panel stands, never with Ctrl,
Meta, or Alt held, never while typing in a text field. A defense
behind a modal decision would hide the decision it needs, so the
incident guard is intentional, not an omission. Do not add an
incident exception here without re-arguing that panel rule: the guard
is intentionally identical to the camera, group, idle, lens, story,
thoughts, claim, proclaim, found, road, visit, model, spotlight, and
build keys, not to Space, P, 0, or M. The Speak For button's title
names it ("Speak For (K key)"), so a desktop player can learn K
exists from the button itself, in the StarCraft II command-hotkey
grammar: the hotkey shown on the button, not only in a tooltip.
