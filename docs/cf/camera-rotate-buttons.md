# Camera rotate buttons

The camera turns on Q/E keys and two-finger pinch, and no on-screen
element ever named either, so a desktop player had no visible way to
turn the view. The speeds row carries two rotate buttons beside the
camera reset, so they ride the thumb-zone move into the tray on phones
exactly like the reset and save-view buttons.

Each tap steps cam.yaw by exactly the Q/E step: left +0.35 (the Q step),
right -0.35 (the E step). The buttons and the keys step the same value
from the same camera, so they cannot disagree, and neither button
clears a camera follow: rotation orbits the followed resident instead
of dropping them. The button titles name the keys they mirror.
