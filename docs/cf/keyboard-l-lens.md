# Keyboard L lens chooser

L is the keyboard twin of the tray Lens button: it runs exactly
the button's verb, toggling lensArm and refreshing the tray, which
renders the lens pick row (Off, Tension, Desire), so the key, the
button, and the pick row can never disagree. The Lens button is
never disabled, so L needs no selection: opening a view layer is
not a resident verb. L is the button's own initial, in the naming
grammar of T for Thoughts, I for Idle, M for Sound, and F for
Follow, and the Lens button's title names it ("Lens (L key)"),
so a desktop player can learn L exists from the button itself.

L is guarded like a panel key, not like the display-only pause and
mute keys: it fires only once the game has started, never while
the game is over, never while an incident panel stands, never with
Ctrl, Meta, or Alt held, and never while typing in a text field.
A pick row over a modal decision would hide the decision it needs,
so the incident guard is intentional, not an omission. Do not add
an incident exception here without re-arguing that panel rule: the
guard is intentionally identical to the camera, group, idle, and
thoughts keys, not to Space, P, 0, or M.
