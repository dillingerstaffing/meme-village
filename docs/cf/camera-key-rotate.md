# Camera key rotate

The Sims 4 camera guides give Q and E as the camera rotate keys, and
Meme Village already serves them, but Q/E were the only camera keys
with no guard: key pan, key zoom, F follow, and R/Home reset all fire
only once the game has started, never while the game is over or an
incident panel is open, never with Ctrl, Meta, or Alt held, and never
while typing in a text field, while Q/E rotated unconditionally. A
player who learned that camera keys stand aside while an incident
decision stands found Q/E still spinning the view behind the panel.

Q or E steps cam.yaw by exactly the rotate button step, left +0.35
for Q, right -0.35 for E, under exactly that same guard. The step and
the follow rule do not change: rotation orbits a followed resident,
it never clears a camera follow, and the rotate buttons are untouched
by this guard, which covers the keys only.
