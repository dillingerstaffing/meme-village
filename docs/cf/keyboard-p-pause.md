# Keyboard P pause

P is the Sims twin of Space for pausing: it toggles speed 0 and 1
(from 2x it pauses, like Space). The Sims 4 lists P as its pause key
in live mode, and Meme Village already paused with Space, but P did
nothing at all, so a Sims player reaching for the canonical pause key
got silence.

P is guarded exactly like Space, including the same deliberate
exception: it fires only once the game has started, never while the
game is over, never with Ctrl, Meta, or Alt held, and never while
typing in a text field, but it STAYS live while an incident panel
stands. Pausing is the thinking tool (while speed is 0 the live toast
holds, never drains), and freezing the sim behind a decision disturbs
nothing, unlike a camera or selection key; the panel still needs its
choice, and the sim already runs at 0.3x behind an incident, so a full
freeze is a smaller step, not a bypass. Do not add an incident guard
here without re-arguing that exception: the guard is intentionally
not identical to the camera keys, exactly as Space is.
