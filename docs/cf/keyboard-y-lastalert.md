# Keyboard Y last alert

Y is the keyboard twin of the last-alert chip: it runs exactly the
chip's verb, the shared __lastAlertFocus call, so the key and the
chip can never disagree. One press jumps the camera to the last
alert's site (the live centroid of its focus ids, or its stored
x/z), clears the camera follow like every other camera jump, and
answers with the tap blip; a focus whose residents are all gone
keeps the chip's own answer instead, the "No site to return to"
toast with the lastAlertClear dispatch. Y is a camera verb, not a
resident verb: it needs no selection and never changes one, and
with no last alert it does nothing, like F with no selection.

The verb it twins is the StarCraft II Cycle Notifications grammar:
Blizzard's own simplified-controls guide names Spacebar as the key
that "Centers the camera on the last warning notification, such as
'base is under attack'", and the classic battle.net control page
says to "press the Space Bar to center the screen on the location
of the last transmission". This game adapts the verb instead of
copying the key, because Space is pause here in the Sims grammar,
settled: Y takes the return, and the chip's title names it
("Return to the last alert (Y)"), so a desktop player can learn Y
exists from the chip itself, in the StarCraft II command-hotkey
grammar: the hotkey shown on the button, not only in a tooltip.

Y is a free letter. A, S, D, and W pan the camera, Q and E rotate
it, R resets it, F follows the selected resident, X saves a camera
mark, and every other letter is a tray verb (B proclaim, C claim,
G spotlight, H road, I idle, J story, K speak, L lens, M mute, N
found, O model, P pause, T thoughts, U build, V visit) or a speed
key. Z stays free; do not spend it on a second return verb without
re-arguing the one-key-one-verb rule this article states.

Y is guarded like every other camera key: it fires only once the
game has started, never while the game is over, never while an
incident panel stands, never with Ctrl, Meta, or Alt held, and
never while typing in a text field. A return behind a modal
decision would move nothing the player can see, and a return while
typing would steal the letter, so both guards are intentional, not
omissions.

Shared guard (2026-11-06): while a Story panel stands open, the shared keydown guard returns before this verb, so it never acts behind the chronicle; Escape, the pause keys, the speed keys, and M stay live. See story-panel-key-guard.md.
