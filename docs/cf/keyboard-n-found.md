# Keyboard N found arm

N is the keyboard twin of the tray Found button: it runs exactly
the button's verb, toggling foundArm and refreshing the tray, so
the key and the button can never disagree. The Found button is
never disabled, so N needs no selection: arming the founding verb
is not a resident verb. F is taken (Follow, the camera key), so
N stands for New: founding starts a new building on a surveyed
plot. The Found button's title names it ("Found (N key)"), so a
desktop player can learn N exists from the button itself.

N carries the button's whole verb, not just its toggle: it clears
foundPlot and the button's own armed-verb clear list (Proclaim,
Speak, Cover, Groups) and toasts on arming, with the surveyed-plot
wording and the next-rung read ("Tap a surveyed plot (gold ring)
to found a building", plus the locked kinds behind the next
kind-bearing rung). It deliberately does not clear the other armed
verbs the button leaves alone: Claim, Road, and the map-targeted
arms keep the button's own grammar, so the key mirrors the button
instead of inventing a wider clear.

N is guarded like a panel key, not like the display-only pause and
mute keys: it fires only once the game has started, never while
the game is over, never while an incident panel stands, never with
Ctrl, Meta, or Alt held, and never while typing in a text field.
An armed verb over a modal decision would hide the decision it
needs, so the incident guard is intentional, not an omission. Do not
add an incident exception here without re-arguing that panel rule:
the guard is intentionally identical to the camera, group, idle,
lens, story, thoughts, claim, and proclaim keys, not to Space, P, 0, or M.
