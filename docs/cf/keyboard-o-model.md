# Keyboard O model arm

O is the keyboard twin of the tray Model button: it runs exactly
the button's verb, toggling modelArm and refreshing the tray, so
the key and the button can never disagree. The Model button is
disabled with no selection, so O needs a selection too: arming a
resident-targeted verb with no subject would leave the gold armed
treatment standing over nobody, and the next resident tap would
eat the model pick instead of selecting. Model's initial M is
already the Sound mute key, so O, the button's second letter,
stands for it; O is claimed by no other key, so no mnemonic
compromise beyond the second letter is needed. It is the second
resident-targeted armed verb to gain a key, after Visit.

O carries the button's whole verb, not just its toggle: it clears
the button's own armed-verb clear list (the generic arm flag,
Visit, Proclaim, Speak, Cover, Groups) and toasts on arming with
the tap-who wording naming the selected resident ("Tap who X
should look up to: they copy them until you pick again"), plus
the current model when one stands ("X looks up to Y now"). It
deliberately does not clear the state the button leaves alone:
Found, Claim, and Road keep the button's own grammar, so the key
mirrors the button instead of inventing a wider clear. The Model
button's title names it ("Model (O key)"), so a desktop player
can learn O exists from the button itself.

O is guarded like a panel key, not like the display-only pause and
mute keys: it fires only once the game has started, never while
the game is over, never while an incident panel stands, never with
Ctrl, Meta, or Alt held, never while typing in a text field, and
never with no selection. An armed verb over a modal decision would
hide the decision it needs, so the incident guard is intentional,
not an omission. Do not add an incident exception here without
re-arguing that panel rule: the guard is intentionally identical
to the camera, group, idle, lens, story, thoughts, claim,
proclaim, found, road, and visit keys, not to Space, P, 0, or M.
