# Keyboard C claim arm

C is the keyboard twin of the tray Claim button: it runs exactly
the button's verb, toggling claimArm and refreshing the tray, which
renders the bearing-plus-ring pick row, so the key, the button, and
the pick row can never disagree. The Claim button is never disabled,
so C needs no selection: opening the Town-tier BUILD verb is not a
resident verb. C is the button's own initial, in the naming grammar
of L for Lens, T for Thoughts, I for Idle, M for Sound, and F for
Follow, and the Claim button's title names it ("Claim (C key)"),
so a desktop player can learn C exists from the button itself.

Shift plus C is not Claim: it is the Cover chord (see
keyboard-shiftc-cover.md), so the plain C key stands aside while
Shift is held, exactly as a digit stands aside for its Shift assign.

C carries the button's Town gate, not just its toggle: below Town
it explains the unlock ("Claims unlock when the village grows into
a Town") instead of arming, and at Town it toggles claimArm, clears
the bearing and ring picks and the button's own armed-verb clear
list (including Found), and toasts on arming, with the in-flight
recall wording when a claim party is already out.

C is guarded like a panel key, not like the display-only pause and
mute keys: it fires only once the game has started, never while
the game is over, never while an incident panel stands, never with
Shift, Ctrl, Meta, or Alt held, and never while typing in a text
field.
A pick row over a modal decision would hide the decision it needs,
so the incident guard is intentional, not an omission. Do not add
an incident exception here without re-arguing that panel rule: the
guard is intentionally identical to the camera, group, idle, lens,
story, and thoughts keys, not to Space, P, 0, or M.

Below Town, the unlock explanation jumps the toast queue, on the
direct-reply rule the group answers already follow: the press arms
nothing and opens no pick row, so a queued answer would read as a
dead key, and the displaced toast waits at the head of the queue
instead of being erased. The tray Claim button's locked answer jumps
on the same rule. Guarded by pwtest_claimroadlock.py in this goal's
hidden_files.
