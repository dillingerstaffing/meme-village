# Keyboard B proclaim arm

B is the keyboard twin of the tray Proclaim button: it runs exactly
the button's verb, toggling proclaimArm and refreshing the tray, so
the key and the button can never disagree. The Proclaim button is
never disabled, so B needs no selection: arming the season-focus
verb is not a resident verb. P is taken (pause, the Sims twin), so
B stands for Broadcast: proclaiming the village focus broadcasts it
to the residents, drawing more of them to work there. The Proclaim
button's title names it ("Proclaim (B key)"), so a desktop player
can learn B exists from the button itself.

B carries the button's whole verb, not just its toggle: it clears
the button's own armed-verb clear list (including Found) and toasts
on arming, with the early-focus wording when the focus was set this
week ("holds the focus now. Shifting the focus early costs cohesion").

B is guarded like a panel key, not like the display-only pause and
mute keys: it fires only once the game has started, never while
the game is over, never while an incident panel stands, never with
Ctrl, Meta, or Alt held, and never while typing in a text field.
An armed verb over a modal decision would hide the decision it
needs, so the incident guard is intentional, not an omission. Do not
add an incident exception here without re-arguing that panel rule:
the guard is intentionally identical to the camera, group, idle,
lens, story, thoughts, and claim keys, not to Space, P, 0, or M.
