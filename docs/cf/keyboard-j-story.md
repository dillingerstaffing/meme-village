# Keyboard J story panel

J is the keyboard twin of the tray Story button: it runs exactly
the button's verb, storySoFar(false), opening the village chronicle
panel (THE STORY SO FAR), so the key, the button, and the panel can
never disagree. The Story button is never disabled, so J needs no
selection: reading the chronicle is not a resident verb. Escape
already closes the panel, so J completes the open and close pair.
S cannot be claimed: it pans the camera down in WASD. J is the
journal key convention (Enshrouded opens its Journal with J), and
the Story panel is this game's journal, its chronicle of the
village so far, and the Story button's title names it
("Story (J key)"), so a desktop player can learn J exists from the
button itself.

J is guarded like a panel key, not like the display-only pause and
mute keys: it fires only once the game has started, never while
the game is over, never while an incident panel stands, never with
Ctrl, Meta, or Alt held, and never while typing in a text field.
A story panel over a modal decision would hide the decision it
needs, so the incident guard is intentional, not an omission. Do
not add an incident exception here without re-arguing that panel
rule: the guard is intentionally identical to the camera, group,
idle, lens, and thoughts keys, not to Space, P, 0, or M.
